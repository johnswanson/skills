# Lyrics

Write a song about the prompted topic in the prompted style. Make sure it slaps.

## Format
- Every annotation belongs in square brackets, e.g. `[Bridge - quiet, almost spoken]`
- Lyrics are plain text with no markdown emphasis. Write loudness in capitals (`SPLASH`), not in bold.
- Write repeated choruses out in full, because Suno sings only what is on the page.
- Put one blank line between sections.
